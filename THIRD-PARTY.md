Los textos de licencia incluidos en `docs/licenses/` deben conservarse con la redistribución. Fuse.js 7.5.0 usa Apache-2.0; no se atribuye una licencia MIT por memoria de versiones anteriores. Leaflet usa BSD-2-Clause. Los datos OSM usan ODbL de forma independiente.

React 19.3 y Vite 8 están publicados en sus documentos oficiales; Vite admite Node 22.12+. Node 24 recomendado para este proyecto. La versión final del lockfile controla instalaciones con `npm ci`.

Documentación oficial: https://react.dev/versions ; https://vite.dev/guide/ ; https://leafletjs.com/ ; https://www.fusejs.io/ ; https://zod.dev/ .
